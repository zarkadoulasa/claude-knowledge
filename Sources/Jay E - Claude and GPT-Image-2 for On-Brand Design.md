# Jay E - Claude and GPT-Image-2 for On-Brand Design

> **Creator:** [[Jay E]] · **Published:** 2026-04-22 · **Length:** 15:07 · [Watch on YouTube](https://www.youtube.com/watch?v=uuP3lDlKfCI)

## TL;DR

A launch-day demo: he says OpenAI released GPT Image 2 that day [00:36](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=36s), and the video went up the next day. Jay E (RoboNuggets) plugs the model into [[Claude Code]] through his own skill, which calls it on the fal.ai model aggregator, so Claude writes every image prompt. The video shows four workflows:

1. **On-brand batch:** one prompt makes a set of assets, with a brand book and logo as references.
2. **Numbered grid:** a 5×5 grid of variants costs one image, then the chosen cell is regenerated at high quality.
3. **Image to video:** pasting fal's docs adds Kling 3.0 to the same skill, then a still gets animated.
4. **Mockup to HTML:** a generated UI mockup becomes HTML, which he says gets only 50–60% of the way.

Results are judged by eye, and keys, costs and reference hosting go unmentioned. The leaderboard lead he cites is from launch week; GPT Image 2.5 now ranks higher (see Beyond the source).

## Key takeaways

- **Let Claude write the prompts.** Drive the image model from an agent, so you never write image prompts yourself [04:30](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=270s). See [[Generating Images and Video with Claude]].
- **Brand references keep outputs on brand.** A one-page brand book kept social posts on colour and type, and the words came out correct [01:48](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=108s). See [[Design Systems for Claude]].
- **Set the resolution.** One post was pixelated because it wasn't generated at top resolution [02:05](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=125s).
- **Generate variants cheaply, then spend on the winner** [10:09](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=609s). See [[Generate On-Brand Images from Claude Code]].
- **Grow a skill from provider docs.** fal model pages carry docs written for LLMs; paste them in and ask Claude to add the model [11:49](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=709s).
- **A mockup image is a short spec, not a finished design.** It gets you about 50–60% of the way [13:58](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=838s).
- **You pick by taste.** Ask for several iterations and choose one yourself [14:29](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=869s). Contrast this with the scored reviews in [[Benchmark-Driven Design Critique]].

### [07:39](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=459s) One prompt, an on-brand batch

1. **Ask Claude to use GPT Image 2.** Optionally have it outline its steps first [07:46](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=466s). See [[Plan Before Executing]].
2. **Reference a one-page brand book** with typography and palettes [07:56](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=476s). If you don't have one, his earlier skill builds one from a website, or you can just give Claude the URL [08:04](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=484s).
3. **Paste the file path** [08:16](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=496s) and ask Claude to convert the PDF to JPEG, since the model won't accept PDFs [08:20](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=500s).
4. **Add the logo path**, here a Claude icon kept in RUBRIC [08:39](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=519s).
5. **List every asset in one prompt:** magazine spread, pricing cards, charts, brand kit, ad campaign, merch [08:46](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=526s).
6. **Claude plans the run.** It prepares and converts the references, maps them to each image, writes the prompts and runs nine generations in parallel [09:12](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=552s).
7. **Review the output.** Claude returns file paths [09:27](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=567s). He views them in his own gallery, which he likens to [[Higgsfield]] or Google Flow [09:36](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=576s).

### [09:51](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=591s) Numbered grid, then regenerate

- **Why volume.** Variation and volume let you steer toward the generations that work [10:01](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=601s).
- **One image, 25 variants.** A 5×5 grid is billed as a single image. Numbering the cells 1–25 lets you ask for one later, such as number 8 [10:22](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=622s).
- **What his prompt asks for:** a 5×5 grid of cinematic social ads, each cell numbered in a small white circle at top left, with the brand book and icon paths [10:40](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=640s).
- **Follow-up.** Say number eight worked, and ask for it on its own at the highest quality [11:00](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=660s). Claude finds that cell's prompt and sets quality and resolution to match [11:10](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=670s).

## Caveats & disagreements

### Limits of this video

- **Launch hype.** "Cheat code" is hype. The near-200-point lead [04:08](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=248s) was launch-week data; GPT Image 2.5 now ranks higher (see Beyond the source).
- **Judged by eye.** He checks results by zooming in [02:27](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=147s). The only flaws he shows are the pixelated post and the partial HTML build. The chart numbers and citations aren't checked [03:29](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=209s).
- **Setup gaps.**
  - No mention of an API key or prices.
  - He passes local file paths [08:16](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=496s) and never shows how they reach fal. The README's public-URL rule is under Beyond the source.
  - "Upscale" [10:31](https://www.youtube.com/watch?v=uuP3lDlKfCI&t=631s) really means regenerate, so the result can differ from the chosen cell.
- **Promotion omitted:** a paid-community pitch (06:24–06:46) and affiliate links in the description. RUBRIC, his own product, appears only as his gallery.

## Build from this

- **On-brand image skill.** Keep the JPEG brand book and the logo inside the skill, and add a cost log. See [[Generate On-Brand Images from Claude Code]], [[Build a Reference-Rich Skill]] and [[Create and Reuse a Claude Design System]].
- **Grid with a prompt log.** Save each grid's prompt and settings, so any cell number can be re-rendered reproducibly.
- **Adding a model safely.**
  - Save the pasted docs as one reference file per model.
  - Make one cheap test call.
  - Update the skill's description.
  - See [[Skill Improvement Loop]] and [[Audit Skill Descriptions and Triggers]].
- **Still to motion.** Lock text and aspect ratio, then compare the video frames to the still. See [[Storyboard-First AI Video and Motion Graphics]].
- **Mockup-to-code loop.** Build from the PNG, screenshot it beside the mockup, and iterate. See [[Build a Distinctive Site with Design Skills]] and [[Benchmark-Driven Design Critique]].

## Beyond the source

*Not said in the video. Checked on 2026-09-15 at the links given.*

- **Release dates.**
  - gpt-image-2 (ChatGPT Images 2.0) launched on 2026-04-21.
  - GPT Image 2.5 followed on 2026-09-08, with two API variants: Flare (speed) and Sunburst (detail).
  - Sources: [OpenAI 2.0](https://openai.com/index/introducing-chatgpt-images-2-0/), [Axios](https://www.axios.com/2026/04/21/chatgpt-images-major-update), [OpenAI 2.5](https://openai.com/index/introducing-chatgpt-images-2-5/), [Wikipedia](https://en.wikipedia.org/wiki/GPT_Image)
- **Leaderboard.**
  - At launch, Arena put GPT-Image-2 first in Text-to-Image, 242 points ahead of Nano-banana-2 with web search.
  - On the board updated 2026-09-07, gpt-image-2.5 Sunburst and Flare rank first and second, and gpt-image-2 (medium) third.
  - Sources: [Arena on X](https://x.com/arena/status/2046670703311884548), [leaderboard](https://arena.ai/leaderboard/text-to-image)
- **The skill's README.**
  - **Install:** copy SKILL.md to `.claude/skills/gpt-image-2/` and set `FAL_KEY`.
  - **Endpoints:** `openai/gpt-image-2` and `openai/gpt-image-2/edit`.
  - **Cost:** about $0.02, $0.05 or $0.18 per 1536×1024 image at low, medium or high quality. Medium is the default.
  - **Limits:** up to 4 images per call. Reference images must be public URLs.
  - **Licences:** MIT. It points to the awesome-gpt-image-2 prompt library (CC BY 4.0).
  - Source: [GitHub](https://github.com/robonuggets/gpt-image-2-skill)
- **fal pricing and docs.**
  - **Price** varies by size and quality; 1024×1024 is about $0.006 low, $0.053 medium, $0.211 high.
  - **Default quality:** fal's API defaults to high.
  - **Docs:** each model page links an llms.txt, the docs Jay pastes.
  - **Kling 3.0 standard image-to-video:** $0.084 per second without audio.
  - Sources: [GPT Image 2 on fal](https://fal.ai/models/openai/gpt-image-2), [Kling 3.0 on fal](https://fal.ai/models/fal-ai/kling-video/v3/standard/image-to-video)
