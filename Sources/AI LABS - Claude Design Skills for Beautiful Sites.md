# AI LABS - Claude Design Skills for Beautiful Sites

> **Creator:** [[AI LABS]] · **Published:** 2026-08-24 · **Length:** 12:55 · [Watch on YouTube](https://www.youtube.com/watch?v=Ysr7oNDajJI)

## TL;DR

[[AI LABS]] describe themselves as a software company. In this video they review seven open-source design skill collections, mostly running them inside [[Claude Design]], and say they include only the ones that gave them results. **Their premise:** however capable a model is, it designs to a recognisable pattern. Skills written by experienced designers steer it away from that look.

**The skills do three jobs** (the grouping is the vault's):

1. **Generate:** emil-design-eng (Emil Kowalski), web-design-engineer (ConardLi), landing-page-design (elayadesign), build-awwwards-quality-sites (Meng To), and tastemaker.
2. **Refine:** animate (Emil Kowalski), better-layout (Jakub Krehel) and designer-skills' perception laws.
3. **Review:** web-design-engineer's scoring mode, Jakub Krehel's review skill (interface-review), and designer-skills' screen critique.

**Their workflow:** add a skill once in Claude settings, type a slash plus its name with a brief, and answer its intake questions. Then chain a refiner or a reviewer. They claim the same skills give the same result in [[Claude Code]], [[OpenAI Codex]] or any agent.

**How much to trust it.** It's a useful map of what exists, but the evidence is thin:

- Results are judged by eye and described in subjective words.
- The narration describes no side-by-side comparison.
- The install steps amount to "add it from settings".
- Several details differ from the repos today: skill counts, the "perfect score", and a review skill that returns a verdict, not a score.

See Caveats and Beyond the source.

## Key takeaways

- **A capable model still has a signature look.** You need something to steer it off that pattern [00:21](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=21s), [00:28](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=28s). See [[Escaping the Default AI Design Look]].
- **Judge a skill by its output, not its workflow.** Elaborate workflows can still produce a site like every other, and only a few skills deliver [00:07](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=7s), [00:13](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=13s). See [[Build vs Install Third-Party Skills]].
- **Skills package a designer's tested workflow** for reuse [00:32](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=32s), [00:36](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=36s). See [[Agent Skills]].
- **One install, several surfaces (their claim).** Skills added in Claude settings are the ones Claude Design uses [00:51](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=51s), [01:00](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=60s). They say the same skills give the same result in Claude Code, Codex or any agent [01:02](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=62s), [01:07](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=67s). See [[Tool-Agnostic Context Files]].
- **Call the skill by name, then answer its questions.** Type a slash, the skill name and a brief [02:12](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=132s). Build skills interview you before building, as Claude Design does by default [02:23](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=143s), [02:27](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=147s).
- **Generate first, then refine.** They start with emil-design-eng [01:57](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=117s) and polish motion on the built site with animate [02:40](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=160s).

See [[Build a Reference-Rich Skill]].
- **A landing page isn't a homepage.** It has one job, getting one action, and the page is structured around it [05:47](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=347s), [06:03](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=363s).
- **Close the loop with a reviewer.**
  - Score, fix, then rerun [05:03](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=303s), [05:09](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=309s).
  - Compare the design before and after your change [09:28](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=568s).
  - List what's wrong [12:05](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=725s).

  See [[Verification Before Done]], [[Build Verification into Every Task]] and [[Skill Improvement Loop]].
- **Layout is Claude Design's weak spot**, in their view. better-layout flags spacing and alignment problems down to the pixel [09:50](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=590s), [10:01](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=601s).

## The seven collections at a glance

**Roles:** Generate builds from a prompt; Refine improves an existing build; Review scores a design or lists its problems. The role labels are the vault's grouping. "Good for" is AI LABS' view from single demos judged by eye. Repo links are under Resources mentioned.

| designer-skills | Owl-Listener (not named in the video) | Review + Refine | screen critique, perception laws | Research-based critique of a finished screen; refinement from how the eye perceives design | [11:21](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=681s) |

**How the roles chain** (the vault's reading):

1. Start with a generator.
2. Refine with animate or better-layout.
3. Review with web-design-engineer's scoring, interface-review or screen critique.
4. Fix what it finds and rerun.

Only the first two steps are shown back to back, as emil-design-eng followed by animate [02:17](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=137s), [02:40](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=160s). The other skills are separate demos.

## Notes by chapter

### [00:00](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=0s) Intro

- **The problem.** Many design skills exist, but not all work. Some run impressive workflows and still produce a site that looks like every other [00:05](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=5s), [00:09](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=9s). Only a few deliver [00:13](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=13s).
- **Why use skills if models already design well?** Each model has its own pattern that's easy to spot, and you need something to push it off that pattern [00:21](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=21s), [00:28](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=28s). See [[Escaping the Default AI Design Look]].
- **Where the skills come from.** Experienced designers packaged workflows they had tested into reusable skills [00:32](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=32s), [00:36](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=36s).
- **Framing.** AI LABS call themselves a software company and say they cover only skills that gave them results [00:43](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=43s), [00:47](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=47s).
- **No separate Claude Design install.** Skills in your Claude setup are the ones Claude Design uses, so you add them from settings [00:51](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=51s), [01:00](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=60s). Anthropic's docs describe the settings route but don't mention Claude Design (Beyond the source).
- **Portability claim.** They say the same skills give the same result in Claude Code, Codex or any agent [01:02](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=62s), [01:07](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=67s), but don't demonstrate it. ### [01:10](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=70s) Emil Kowalski's skills

- **The set.** The video counts nine skills, each changing a different part of a design [01:13](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=73s), [01:15](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=75s); the repo now has 12 (Beyond the source). AI LABS use them in both Claude Code and Claude Design [01:19](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=79s), [01:22](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=82s).
- **apple-design** brings Apple's product design principles to other sites [01:27](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=87s), [01:32](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=92s).
- **animation-vocabulary** turns a vague description of motion into exact terms a model understands [01:35](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=95s), [01:39](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=99s).
- **Their two most-used skills** [01:45](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=105s):
  - **emil-design-eng** covers building beautiful UI components and animating them. It's their starting skill [01:53](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=113s), [01:57](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=117s).
  - **animate** is a full, step-by-step workflow for animating a site that's already built [02:01](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=121s), [02:05](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=125s).
- **How to run a skill.** Add it to Claude, open Claude Design, type a slash and the skill name, then describe the site [02:09](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=129s), [02:14](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=134s).
- **Demo 1: emil-design-eng from scratch.**
  1. With nothing built yet, they ran emil-design-eng [02:17](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=137s).
  2. It loaded and asked about the app before building, as Claude Design does on its own [02:23](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=143s), [02:27](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=147s).
  3. **Result:** a minimal, monotone first version. Its animations were unpolished and out of sync in places [02:31](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=151s), [02:36](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=156s).
- **Demo 2: animate on that build.** It works out how the site functions and decides what should move and what shouldn't [02:44](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=164s), [02:48](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=168s). Afterwards, motion followed the scroll and the site felt more intentional [02:54](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=174s), [02:57](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=177s).
- **Their own caveat.** On a landing page the gain looks modest. animate improved the subtle details, but landing pages benefit most from scroll-based animation, which earlier videos covered [02:59](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=179s), [03:12](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=192s).
- **Where animate works best: small functional UI** [03:18](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=198s). On a restaurant site it added a form-submit animation and hover pop-ups [03:24](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=204s), [03:35](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=215s). Those details made the site feel much more interactive [03:38](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=218s).
- **Their advice:** add as many of Emil's skills as you like [03:42](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=222s), [03:46](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=226s). Other sources push back on this (see Caveats).

### [03:49](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=229s) Garden skill

  - how to judge a design
  - common ways designs fail

  [04:34](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=274s), [04:40](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=280s). See [[Build a Reference-Rich Skill]].

- **Review mode.**
  - Run it on an existing design and it scores several areas [05:01](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=301s), [05:05](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=305s).
  - Their loop: refine and rerun until the score is perfect and the design is what you intended [05:09](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=309s), [05:14](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=314s).
  - The repo's critique scores five dimensions from 0 to 10, so set a threshold instead (Beyond the source). See [[Build Verification into Every Task]].

### [05:24](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=324s) Landing page skill

- **The skill.** elayadesign's landing-page-design is one skill in one file [05:27](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=327s), [05:31](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=331s).

  - Covers things models overlook, including whether the page can be found in search [06:16](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=376s), [06:20](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=380s). The SKILL.md does include an indexing section (Beyond the source).

## Caveats & disagreements

**About the video itself**

- **Results are judged by eye.** The words are "more intentional" [02:56](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=176s), "a lot more interesting" [04:53](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=293s) and "looked really impressive" [11:15](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=675s).
  - No brief is run through more than one skill, no scores are read out, and there are no metrics.
  - The claim that purchases became more likely [06:36](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=396s) has no data behind it.
  - No failing skills are named, despite the claim that only a few deliver [00:13](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=13s).
- **"Same result" in any agent is asserted, not shown** [01:07](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=67s). The repos do target several agents, but:
  - tastemaker's scripts need code execution, and its README calls Cursor support degraded.
  - interface-review needs git history.
  - Install paths differ from one agent to another.
- **Skills inside Claude Design rest on the video alone** [00:51](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=51s). Anthropic's pages describe uploading skills and describe Claude Design, but none says the two connect.
- **Install steps are skipped.** "Add it from Claude settings" [01:00](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=60s) is all you get. The actual commands are under Beyond the source.
- **Names and counts drift.**
  - The video says nine Emil skills [01:13](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=73s); the repo now has 12.
  - "Perception laws" [11:55](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=715s) isn't a skill name. The closest match is the Gestalt law-of-* skills.
  - "Screen critique" [11:45](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=705s) is a command that runs seven critique skills.
- **"Perfect score" oversells it** [05:12](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=312s).
  - web-design-engineer scores five dimensions from 0 to 10, so set a threshold and a cap on rounds.
  - interface-review returns a verdict and a findings table, not the score implied at [09:22](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=562s).
- **"Connect it to GitHub" really means git** [09:24](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=564s). interface-review works on a diff, a branch or a PR number, which suits Claude Code in a repo better than browser-based Claude Design. It also runs only when you invoke it yourself.
- **Third-party code runs on your machine.** video-to-superprompt uses local tools [07:57](https://www.youtube.com/watch?v=Ysr7oNDajJI&t=477s), and tastemaker runs Python and fetches icons. Read a skill before installing it.

- **Claude Design.**
  - In beta on Pro, Max, Team and Enterprise (off by default on Enterprise), at claude.ai/design or in Claude Desktop.
  - Neither the help article nor the April 2026 launch post mentions custom skills.
  - The launch post describes a handoff bundle for Claude Code. The help article and product page name `/design-sync`, and the product page also names `/design`, for moving work between the two. In the vault's reading, that handoff is how a design would reach a git-based reviewer like interface-review.
  - https://support.claude.com/en/articles/14604416-get-started-with-claude-design · https://www.anthropic.com/news/claude-design-anthropic-labs · https://claude.com/product/design

  - Personal skills go in `~/.claude/skills/<name>/SKILL.md`; project skills go in `.claude/skills/<name>/SKILL.md`.
  - `disable-model-invocation: true` means only you can trigger the skill.
  - Skills follow the Agent Skills open standard.
  - Keep SKILL.md under about 500 lines. Reference files load only when needed, and scripts run without entering context.
  - https://code.claude.com/docs/en/skills
- **Anthropic's frontend-design skill** targets the same generic-aesthetics problem through deliberate choices of typography, colour, composition and motion. https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md
- **skills.sh** is a directory of agent skills. `npx skills add <owner/repo>` installs a skill into many agents, including Claude Code and Cursor. https://skills.sh

**The seven repos today**

- **Emil Kowalski.**
  - 12 skills. Beyond the video's four: animate-expo, review-animations, improve-animations, find-animation-opportunities, write-swift, pick-ui-library, prototype, ask-sonner.
  - Install: `npx skills@latest add emilkowalski/skills`.
  - **animate's rules:**
    - No motion at all on actions used 100 or more times a day.
    - A purpose for every animation.
    - Animate transform and opacity only.
    - Keep UI animations under 300 ms.
    - Gentler, not zero, motion for reduced-motion users.
  - https://github.com/emilkowalski/skills · https://github.com/emilkowalski/skills/blob/main/skills/animate/SKILL.md
- **ConardLi garden-skills.**
  - Five skills: web-video-presentation, web-design-engineer, gpt-image-2, kb-retriever, beautiful-article.
  - Tested on Claude Code, Claude.ai, Cursor, Codex CLI, Gemini CLI and OpenCode.
  - Install: `npx skills add ConardLi/garden-skills`, or the Claude Code plugin marketplace.
  - **How web-design-engineer works:**
    - It declares a design system and waits for your approval before coding.
    - It ships an early v0.
    - It ranks design anchors from your own assets down to a style recipe. There are 25 recipes, including `apple-hig.md` and `linear.md`.
  - **Its critique** runs when you ask for a review, or as a self-check before delivery. It scores five dimensions from 0 to 10 (philosophy alignment, visual hierarchy, craft quality, functionality, originality) and returns Keep, Fixes and three Quick Wins.
  - The README credits Claude Design's system prompt as the inspiration for web-design-engineer.
  - https://github.com/ConardLi/garden-skills · https://github.com/ConardLi/garden-skills/blob/main/skills/web-design-engineer/SKILL.md
- **elayadesign landing-page-design.**
  - Intake covers the primary action and offer, target customer, objections, traffic source, proof and voice.
  - Its rule is one offer, one audience and one primary action.
  - The visual system is strict: one typeface per site, fixed spacing tokens, Tailwind radii and flat backgrounds.
