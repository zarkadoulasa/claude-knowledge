# AI LABS - Design Skills from Landing Pages to Mobile Apps

> **Creator:** [[AI LABS]] · **Published:** 2026-06-23 · **Length:** 14:14 · [Watch on YouTube](https://www.youtube.com/watch?v=Ot582-E61ac)

## TL;DR

[[AI LABS]] say capable models still drift to one safe look, and the right skill hands the model a decision before code. The roundup is sorted by job:

1. **Direction:** Anthropic's frontend-design skill.
2. **Functional UI:** shadcn skill plus shadcn MCP, and a dashboard skill.
3. **Design system:** UI UX Pro Max.
4. **Motion:** GSAP's official skills.
5. **Taste presets:** one at a time.
6. **Media:** Higgsfield.
7. **Mobile:** principles plus Material 3, SwiftUI or Expo.

**Caution.** The title and #claudedesign aside, the [[Claude Design]] product never appears. The only surface named is the terminal [10:55](https://www.youtube.com/watch?v=Ot582-E61ac&t=655s), and there's one demo.

**Not the August video.** [[AI LABS - Claude Design Skills for Beautiful Sites]] covers different skills. New here:
- the marketing vs functional UI split
- component registries and skill + MCP pairing
- a decide-before-build engine
- animation performance
- generated visuals
- mobile platform skills
- re-tuning skills for new models

## Key takeaways

- **Match the skill to the kind of UI.** Anthropic's skill struggles with functional UI [02:47](https://www.youtube.com/watch?v=Ot582-E61ac&t=167s), so AI LABS keep separate marketing and functional skills [02:12](https://www.youtube.com/watch?v=Ot582-E61ac&t=132s). See [[Design Systems for Claude]].
- **Art direction is for marketing surfaces;** their community's functional layer looks plain [03:06](https://www.youtube.com/watch?v=Ot582-E61ac&t=186s). A scope limit for [[Escaping the Default AI Design Look]].
- **Assemble, don't generate.** Ship-ready registry parts beat polishing a draft [03:52](https://www.youtube.com/watch?v=Ot582-E61ac&t=232s). See [[Build Product UI from a Component Registry]].
- **A decision beats taste:** generate a product-specific design system first [06:46](https://www.youtube.com/watch?v=Ot582-E61ac&t=406s).
- **Skills can delegate:** their marketing skill hands animation to the GSAP skill [09:21](https://www.youtube.com/watch?v=Ot582-E61ac&t=561s).
- **Re-tune design prompts when models change** [02:32](https://www.youtube.com/watch?v=Ot582-E61ac&t=152s). See [[Skill Improvement Loop]].
- **Some of the best skills come from tool makers; don't stack presets** [00:24](https://www.youtube.com/watch?v=Ot582-E61ac&t=24s), [10:15](https://www.youtube.com/watch?v=Ot582-E61ac&t=615s). See [[Build vs Install Third-Party Skills]].

## Notes by chapter

*No chapters in the metadata; these sections are the vault's.*

### [00:00](https://www.youtube.com/watch?v=Ot582-E61ac&t=0s) Why AI designs converge

- Models design far better, yet good designs start to look alike [00:05](https://www.youtube.com/watch?v=Ot582-E61ac&t=5s). Skills package the prompts that make the difference [00:14](https://www.youtube.com/watch?v=Ot582-E61ac&t=14s).
- Many design skills don't help. Some of the best come from the tool makers [00:24](https://www.youtube.com/watch?v=Ot582-E61ac&t=24s).

### [00:43](https://www.youtube.com/watch?v=Ot582-E61ac&t=43s) Anthropic's frontend-design skill

- It's the base many design skills build on [00:45](https://www.youtube.com/watch?v=Ot582-E61ac&t=45s).
- **Why sites feel the same:** trained on repetitive data, the model takes the most common option at each design call [01:03](https://www.youtube.com/watch?v=Ot582-E61ac&t=63s).
- **What the skill does:**
  - It forces the model to commit to a direction before code, and hold it [01:20](https://www.youtube.com/watch?v=Ot582-E61ac&t=80s).
  - Its SKILL.md names tells like overused fonts and purple gradients on white [01:32](https://www.youtube.com/watch?v=Ot582-E61ac&t=92s).
- Models optimise landing pages for correctness; this gives them a point of view [01:45](https://www.youtube.com/watch?v=Ot582-E61ac&t=105s). Best for landing pages and portfolios [01:53](https://www.youtube.com/watch?v=Ot582-E61ac&t=113s).
- **Demo:** a landing page free of the usual slop, judged by eye [02:01](https://www.youtube.com/watch?v=Ot582-E61ac&t=121s).

### [02:10](https://www.youtube.com/watch?v=Ot582-E61ac&t=130s) AI LABS's two-skill design system

- A functional skill for dashboards and similar, plus a marketing-UI skill [02:12](https://www.youtube.com/watch?v=Ot582-E61ac&t=132s).
- The marketing SKILL.md holds a "break the default" prompt, a modified frontend-design skill [02:23](https://www.youtube.com/watch?v=Ot582-E61ac&t=143s).
- The original is outdated: the Opus 4.8 and Fable 5 prompting guides show how instructions must change [02:32](https://www.youtube.com/watch?v=Ot582-E61ac&t=152s). See [[Choosing a Claude Model]].

### [02:46](https://www.youtube.com/watch?v=Ot582-E61ac&t=166s) Functional UI with shadcn

- Products need many components that all behave [02:58](https://www.youtube.com/watch?v=Ot582-E61ac&t=178s). Common dashboard components already exist, professionally built [03:21](https://www.youtube.com/watch?v=Ot582-E61ac&t=201s), and the model pulls them from the registry [03:35](https://www.youtube.com/watch?v=Ot582-E61ac&t=215s).
- **Skill:** shadcn's rulebook. It inspects your project so output fits [04:10](https://www.youtube.com/watch?v=Ot582-E61ac&t=250s) and is clean first time [04:22](https://www.youtube.com/watch?v=Ot582-E61ac&t=262s).
- **MCP:** a live registry connection [04:28](https://www.youtube.com/watch?v=Ot582-E61ac&t=268s).
- **Why both:** they call skill and MCP two parts that work together [04:01](https://www.youtube.com/watch?v=Ot582-E61ac&t=241s), and say skills load on demand while MCP sits in context [04:43](https://www.youtube.com/watch?v=Ot582-E61ac&t=283s). The skill's rules, patterns and project context give the agent judgement to use components correctly [04:49](https://www.youtube.com/watch?v=Ot582-E61ac&t=289s). See [[shadcn]], [[Connecting Claude to External Tools]].

### [04:56](https://www.youtube.com/watch?v=Ot582-E61ac&t=296s) Dashboards

- The core problem is arranging information: grouping, and how much fits before clutter [05:14](https://www.youtube.com/watch?v=Ot582-E61ac&t=314s). A separate dashboard skill reasons through that first [05:26](https://www.youtube.com/watch?v=Ot582-E61ac&t=326s).

### [05:32](https://www.youtube.com/watch?v=Ot582-E61ac&t=332s) UI UX Pro Max

- Principles alone still leave the model deciding what fits the product [05:44](https://www.youtube.com/watch?v=Ot582-E61ac&t=344s). One generic idea of "good" makes everything alike [05:52](https://www.youtube.com/watch?v=Ot582-E61ac&t=352s).
- **How the engine works:**
  1. It fires five searches at once over an open-source database [06:05](https://www.youtube.com/watch?v=Ot582-E61ac&t=365s), covering 161 industry categories [06:13](https://www.youtube.com/watch?v=Ot582-E61ac&t=373s).
  2. It picks a palette, font pairing and layout [06:16](https://www.youtube.com/watch?v=Ot582-E61ac&t=376s).
  3. It filters out mismatches and hands over a tailored design system [06:23](https://www.youtube.com/watch?v=Ot582-E61ac&t=383s).
- See [[Create and Reuse a Claude Design System]].

### [07:50](https://www.youtube.com/watch?v=Ot582-E61ac&t=470s) Motion with GSAP

- They claim animation lifts time on site [07:59](https://www.youtube.com/watch?v=Ot582-E61ac&t=479s), but models almost always add the same slide-in on scroll [08:13](https://www.youtube.com/watch?v=Ot582-E61ac&t=493s).

### [11:17](https://www.youtube.com/watch?v=Ot582-E61ac&t=677s) Mobile skills

- Models shrink web habits onto phones [11:25](https://www.youtube.com/watch?v=Ot582-E61ac&t=685s) and ignore thumb reach, navigation and platform design languages [11:34](https://www.youtube.com/watch?v=Ot582-E61ac&t=694s).
- **Principles:** mobile-app-ui-design covers thumb zone, spacing and a small type scale [11:57](https://www.youtube.com/watch?v=Ot582-E61ac&t=717s), the same rules behind Airbnb, Duolingo and Spotify [12:07](https://www.youtube.com/watch?v=Ot582-E61ac&t=727s).
- **Android:** Material 3 is mobile's shadcn [12:16](https://www.youtube.com/watch?v=Ot582-E61ac&t=736s), Google's system behind most Android and Pixel apps. Its language is bold and colourful, with big rounded shapes and springy motion [12:26](https://www.youtube.com/watch?v=Ot582-E61ac&t=746s). One colour yields a theme, and it checks guideline adherence [12:38](https://www.youtube.com/watch?v=Ot582-E61ac&t=758s).
- **iOS:** Apple's language is the restrained opposite, leaning on translucent Liquid Glass [12:51](https://www.youtube.com/watch?v=Ot582-E61ac&t=771s). SwiftUI skills [12:48](https://www.youtube.com/watch?v=Ot582-E61ac&t=768s) feed Apple's docs from Xcode as rules [13:01](https://www.youtube.com/watch?v=Ot582-E61ac&t=781s).
- **Both:** the official Expo skill [13:20](https://www.youtube.com/watch?v=Ot582-E61ac&t=800s).

## Beyond the source

*Not in the video; checked 2026-09-15.*

- **frontend-design now.**
  - Plans first: 4–6 hex colours, typefaces and an ASCII wireframe, checked against the brief.
  - Lists five AI-look clusters (e.g. cream/serif/terracotta) and no longer mentions purple gradients.
  - https://github.com/anthropics/claude-code/blob/main/plugins/frontend-design/skills/frontend-design/SKILL.md
- **shadcn skill.** `pnpm dlx skills add shadcn/ui`. It activates on `components.json` and runs `shadcn info --json`. https://ui.shadcn.com/docs/skills
- **shadcn MCP.** In `.mcp.json`, command `npx`, args `shadcn@latest mcp`. It browses, searches and installs. https://ui.shadcn.com/docs/mcp
- **Tool search** is on by default in Claude Code. It's off with a custom `ANTHROPIC_BASE_URL` or `ENABLE_TOOL_SEARCH=false`. https://code.claude.com/docs/en/mcp
- **UI UX Pro Max.**
  - Install: `/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill`, then `/plugin install ui-ux-pro-max@ui-ux-pro-max-skill`.
  - Python BM25 over five parallel searches.
  - Data: 192 palettes, 74 font pairings, 192 industry reasoning rules.
  - A paid Premium tier exists.
  - https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- **GSAP skills.** `npx skills add https://github.com/greensock/gsap-skills`. Prefer transform aliases and autoAlpha. https://github.com/greensock/gsap-skills
- **Higgsfield.** Connector URL `https://mcp.higgsfield.ai/mcp`. Every agent generation deducts credits. https://higgsfield.ai/creator-hub/help-center/integrations/how-do-i-connect-higgsfield-to-ai-agent
- **Mobile.**
  - mobile-app-ui-design: 8-pt grid; at most four sizes and two weights. https://github.com/ceorkm/mobile-app-ui-design
  - material-3: a 10-category audit, Compose first. https://github.com/hamen/material-3-skill
  - SwiftUI skills: need Xcode 26+. https://github.com/ameyalambat128/swiftui-skills
  - Expo: `claude plugin install expo@claude-plugins-official`. building-native-ui is now expo-native-ui. https://github.com/expo/skills
