## Ideas associated with them

According to the video, these ideas are built into Unlazy:

- **Prove "done" instead of claiming it.** Work is checked against a ledger where every item needs proof ([01:13](https://www.youtube.com/watch?v=c47uqR7XB_c&t=73s), [01:17](https://www.youtube.com/watch?v=c47uqR7XB_c&t=77s)).
- **Put requirements in files, not instructions.** An earlier version asked the agent to be thorough, and that instruction got lost in long sessions. The current one writes gates to a file before any work ([07:12](https://www.youtube.com/watch?v=c47uqR7XB_c&t=432s), [07:21](https://www.youtube.com/watch?v=c47uqR7XB_c&t=441s)).
- **Depth-tree decomposition.** You choose how many layers deep the task is split ([05:31](https://www.youtube.com/watch?v=c47uqR7XB_c&t=331s), [05:55](https://www.youtube.com/watch?v=c47uqR7XB_c&t=355s)).
- **Abandon honestly.** An impossible gate is given up by name, with a reason, rather than dropped silently ([08:53](https://www.youtube.com/watch?v=c47uqR7XB_c&t=533s)).

The general technique is in [[Evidence-Gated Completion Ledger]], and the problem it addresses is [[Agent Laziness]]. His design skill relates to [[Escaping the Default AI Design Look]], though the video doesn't cover it.
