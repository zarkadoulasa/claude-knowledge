## Ideas associated with them

- **The three-step AI website pipeline** — prompt-to-site (Claude Code + a design skill), asset generation (image → video), then integrate and deploy, minimizing tool-hopping ([00:51](https://www.youtube.com/watch?v=ZfYvv-0l9NA&t=51s)).
- **Design "taste" as a portable skill** — a repo of design principles turns a one-line prompt into a high-end, one-shot site ([01:15](https://www.youtube.com/watch?v=ZfYvv-0l9NA&t=75s)); he uses [[Leon Lin]]'s open-source taste skill.
- **Productized-service framing** — reframing a cheap AI build as a premium client deliverable worth thousands ([00:33](https://www.youtube.com/watch?v=ZfYvv-0l9NA&t=33s)).
- **Screenshot-as-feedback** — pasting a screenshot of the rendered page back into Claude Code to point out visual problems in plain language ([06:35](https://www.youtube.com/watch?v=ZfYvv-0l9NA&t=395s)).
- **"Just make it faster" optimization** — repeating a vague performance instruction and accepting the quality/speed tradeoff, which prompts Claude Code to convert a heavy video into preloaded per-frame JPEGs ([09:43](https://www.youtube.com/watch?v=ZfYvv-0l9NA&t=583s)).
