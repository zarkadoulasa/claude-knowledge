## Beyond the source

None of the following comes from either video.

- **Background:** full-time educator and the creator of Total TypeScript, a TypeScript training platform. Previously a developer advocate at Vercel and a member of the XState core team. — [totaltypescript.com](https://www.totaltypescript.com/)
- **Current focus:** his site says he used to be a voice coach, now teaches AI engineering full-time, and is building AI Hero, a course that retrains web developers as AI engineers. — [mattpocock.com](https://www.mattpocock.com/)
- **Skills repo:** `mattpocock/skills`, which the README (checked 2026-09-15) describes as the agent skills he uses every day for real engineering rather than vibe coding. It has an engineering group and a productivity group, and grill-me is in productivity. — [github.com/mattpocock/skills](https://github.com/mattpocock/skills)
  - Install in Claude Code: `/plugin install mattpocock-skills@claude-plugins-official` in a session, or `claude plugin install mattpocock-skills@claude-plugins-official` from the shell. The README spells the shell command `claude plugins install`, but the Claude Code docs document the singular form. — [README](https://github.com/mattpocock/skills), [official marketplace catalog](https://github.com/anthropics/claude-plugins-official/blob/main/.claude-plugin/marketplace.json), [Claude Code docs](https://code.claude.com/docs/en/discover-plugins)
  - Install for other agents: `npx skills@latest add mattpocock/skills`
- **Original grill-me:**
  - Its SKILL.md frames it as a relentless interview to sharpen a plan or design. It is user-invoked only, and its body is a single line that calls the sibling `grilling` skill, which holds the method. — [SKILL.md](https://github.com/mattpocock/skills/blob/main/skills/productivity/grill-me/SKILL.md)
  - The current docs say it asks questions in rounds. Each round covers every question whose prerequisites are already answered.
  - It is stateless (writes no files), and the topic doesn't have to be code. — [docs/productivity/grill-me.md](https://github.com/mattpocock/skills/blob/main/docs/productivity/grill-me.md)
- **Difference to note:** Nate's version writes a brainstorm file ([21:00](https://www.youtube.com/watch?v=DTCyvo6cC54&t=1260s)), but the current upstream skill writes none. Either file-writing is part of Nate's customisation, or the upstream skill has changed since June 2026. The video doesn't say which.
- **grill-with-docs (checked 2026-09-15).**
  - **Location:** the engineering group of `mattpocock/skills`, at `skills/engineering/grill-with-docs/`. The captioned "grow with doc" is this skill.
  - **Purpose:** it interviews you about a plan or design inside an existing repo, and writes docs as it goes.
  - **What it writes:** agreed terms go into a `CONTEXT.md` glossary. Only hard-to-reverse decisions with real trade-offs become ADRs under `docs/adr/`. Most decisions stay in the conversation.
  - **How it asks:** in rounds.
  - **Invocation:** user-invoked only (`disable-model-invocation`). It relies on the sibling grilling and domain-modeling skills.
  - **When not to use it:** its docs point to grill-me when you aren't working in a repo.
  - — [SKILL.md](https://github.com/mattpocock/skills/blob/main/skills/engineering/grill-with-docs/SKILL.md), [docs page](https://github.com/mattpocock/skills/blob/main/docs/engineering/grill-with-docs.md)
- **improve-codebase-architecture (checked 2026-09-15).**
  - **Location:** `skills/engineering/improve-codebase-architecture/`, also user-invoked only.
  - **What it looks for:** it scans the codebase, leaning towards recently changed code, for shallow modules that could become deeper ones.
  - **What it produces:** a self-contained HTML report of candidates, with before/after diagrams and strength badges. *(Vault inference:)* this is most likely the "visual" the video mentions.
  - **Follow-up:** it then grills you on the candidate you pick, updating `CONTEXT.md` and optionally recording ADRs.
  - **Cadence:** its docs frame it as periodic maintenance that queues architectural work rather than changing code during the scan.
  - — [SKILL.md](https://github.com/mattpocock/skills/blob/main/skills/engineering/improve-codebase-architecture/SKILL.md), [docs page](https://github.com/mattpocock/skills/blob/main/docs/engineering/improve-codebase-architecture.md)
- **One-time setup:** the README now says to run `/setup-matt-pocock-skills` once per repo. It configures issue tracking, triage labels and documentation preferences. — [README](https://github.com/mattpocock/skills)
