# The Coding Sloth

## Who

- **Persona:** a joke-heavy developer channel.
- **Plan and limits:** he codes on the $20 plan, where one or two prompts can use up the limit ([00:19](https://www.youtube.com/watch?v=YAsxyoTWFDA&t=19s)).
- **Footage:** much of it was recorded about a month before release ([00:13](https://www.youtube.com/watch?v=YAsxyoTWFDA&t=13s)).
- **Independence:** he says most Claude Code concepts carry over to other coding agents. Because the video isn't sponsored (by Anthropic), he also suggests alternatives ([01:46](https://www.youtube.com/watch?v=YAsxyoTWFDA&t=106s)).
- **Main tool now:** [[OpenAI Codex]], which he says he has used the most. He praises its generous usage limits ([21:04](https://www.youtube.com/watch?v=YAsxyoTWFDA&t=1264s)).

## Where sources disagree

- **Installing community skills.**
  - He reads other people's skills to learn from them ([05:50](https://www.youtube.com/watch?v=YAsxyoTWFDA&t=350s)), and uses skills.sh to find and install them ([05:55](https://www.youtube.com/watch?v=YAsxyoTWFDA&t=355s)).
  - [[Ras Mic - How AI Agents and Claude Skills Work]] says he doesn't install others' skills ([12:39](https://www.youtube.com/watch?v=S_oN3vlzpMw&t=759s)).

## Beyond the source

- **/loop isn't built for durable automations.** Its tasks are session-scoped, and recurring tasks expire after seven days. For unattended scheduling, the docs point to Routines or Desktop scheduled tasks instead. — [Claude Code docs: scheduled tasks](https://code.claude.com/docs/en/scheduled-tasks)
