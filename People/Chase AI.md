## Ideas associated with him

- **Four levels.** → [[Agentic OS]]
  - Level 1 is skills and loop engineering; Level 2 is memory and state ([01:50](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=110s)). Level 3 is the interface ([02:53](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=173s)), and Level 4 is distribution to teammates or clients ([03:10](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=190s)).
  - Levels 1–2 hold about 90% of the value ([02:45](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=165s)).
- **Workflow audit into skills.** → [[Workflow Audit into Skills]]
  - Map domains and the tasks under each ([06:10](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=370s)).
  - Confirm a task works by hand before making it a skill ([07:18](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=438s)).
  - Find candidates by mining past sessions ([07:39](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=459s)) or having Claude interview you ([08:56](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=536s)).
- **Skill, then automation, then loop.** → [[Loop Engineering]]
  - A skill becomes a Routine ([11:25](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=685s)), then gains a self-improvement loop ([11:48](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=708s)).
  - Outputs must be logged where the loop can see them ([22:30](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=1350s)).
- **File structure as a map.** → [[LLM Wiki]], [[Obsidian]]
  - A coherent structure gets you most of the way ([14:06](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=846s)).
  - He credits the layout to a viral [[Andrej Karpathy]] post on an Obsidian knowledge base ([17:20](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=1040s)): raw data, wiki articles, then an outputs folder ([18:33](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=1113s)).
  - Put an index.md at every level ([19:31](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=1171s)).
  - The vault CLAUDE.md sets a navigation pattern ([21:50](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=1310s)).
- **Buttons over terminals.** → [[Build an Agentic OS Dashboard]]
  - Buttons run skills through headless Claude Code ([27:22](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=1642s)).
  - That lets non-technical teammates use them ([28:37](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=1717s)).
- **The May version: three steps.** → [[Agentic OS]], [[Workflow Audit into Skills]]
  - The architecture, not the dashboard, is the real value ([01:14](https://www.youtube.com/watch?v=Bgxsx8slDEA&t=74s)).
  - He builds it through a spoken brain-dump conversation ([05:10](https://www.youtube.com/watch?v=Bgxsx8slDEA&t=310s)). Claude turns each task into a skill with skill-creator, then decides whether it needs automating, locally or remotely ([05:51](https://www.youtube.com/watch?v=Bgxsx8slDEA&t=351s)).
  - For memory he uses a vault laid out as raw, wiki and output, credited to Karpathy ([09:03](https://www.youtube.com/watch?v=Bgxsx8slDEA&t=543s)). Its CLAUDE.md states the system's purpose and how memory is structured ([11:48](https://www.youtube.com/watch?v=Bgxsx8slDEA&t=708s)).
  - Dashboard buttons start headless `claude -p` runs ([13:45](https://www.youtube.com/watch?v=Bgxsx8slDEA&t=825s)). They mostly help teammates and clients, not people already fluent in the terminal ([13:58](https://www.youtube.com/watch?v=Bgxsx8slDEA&t=838s)).
- **Storyboard before slow execution.** → [[Storyboard-First AI Video and Motion Graphics]]
  - An After Effects graphic can take 10–20 minutes to build, so agree a storyboard first ([01:50](https://www.youtube.com/watch?v=C8dWdic-oK4&t=110s), [02:31](https://www.youtube.com/watch?v=C8dWdic-oK4&t=151s)).
  - Have the agent write the build prompt itself, broken into beats taken from the storyboard ([04:18](https://www.youtube.com/watch?v=C8dWdic-oK4&t=258s), [04:38](https://www.youtube.com/watch?v=C8dWdic-oK4&t=278s)).
  - Watch pacing: unless you control transitions, scenes drag at 2.5–3 seconds each ([07:04](https://www.youtube.com/watch?v=C8dWdic-oK4&t=424s)).
  - In Claude Code you would need to add image generation, e.g. through the [[Higgsfield]] MCP ([02:58](https://www.youtube.com/watch?v=C8dWdic-oK4&t=178s)).

## Where sources disagree

- **What goes into the vault.**
  - Chase would copy a whole domain's data, such as all sales data, into the vault ([15:12](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=912s)).
  - [[Nate Herk - Every Level of a Claude Second Brain]] keeps changing data like email and customer records out ([27:25](https://www.youtube.com/watch?v=DTCyvo6cC54&t=1645s)), but reachable ([28:04](https://www.youtube.com/watch?v=DTCyvo6cC54&t=1684s)). → [[Context vs Connections]]
- **When to build a skill.**
  - In May, Claude turns each task you describe into a skill during the conversation ([05:51](https://www.youtube.com/watch?v=Bgxsx8slDEA&t=351s)).
  - In June, he says to confirm the task works by hand first ([07:18](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=438s)).
- **Loops, by Chase's own account.**
  - June: a skill becomes an automation, then a self-improving loop ([11:48](https://www.youtube.com/watch?v=HRw-vP0j8OM&t=708s)).
  - September: avoid loops for slow creative work unless you really know what you're doing, and keep a human in the loop ([07:27](https://www.youtube.com/watch?v=C8dWdic-oK4&t=447s), [07:39](https://www.youtube.com/watch?v=C8dWdic-oK4&t=459s)).
  - What decides it is how long each pass takes. → [[Loop Engineering]]
- **How much retrieval you need.**
  - Chase says 99.9% of people need neither [[LightRAG]] nor a vector database ([11:02](https://www.youtube.com/watch?v=Bgxsx8slDEA&t=662s)).
  - [[Nate Herk - Set Up the Karpathy LLM Wiki with Obsidian]] draws the line at scale: hundreds of pages suit a wiki, while millions of documents need RAG ([17:10](https://www.youtube.com/watch?v=sboNwYmH3AY&t=1030s)).

## Beyond the source

- **Name:** chaseai.io, linked from the video description, names its founder as Chase Hannegan. — [chaseai.io](https://www.chaseai.io/)
- **CLAUDE.md isn't appended to every prompt** (checked 2026-09-15). He says it effectively is ([11:43](https://www.youtube.com/watch?v=Bgxsx8slDEA&t=703s)). The docs say it loads at the start of each session, as a user message after the system prompt, and stays in context. — [Claude Code docs: memory](https://code.claude.com/docs/en/memory)
- **Local or remote isn't only Claude's call** ([05:51](https://www.youtube.com/watch?v=Bgxsx8slDEA&t=351s)).
  - Cloud routines run with the machine off, but on a fresh clone with no local files, and at most once an hour.
  - Desktop tasks can reach local files but need the machine on.
  - A job that writes into a local vault therefore has to run locally.
  - — [Claude Code docs: scheduled tasks](https://code.claude.com/docs/en/scheduled-tasks)
