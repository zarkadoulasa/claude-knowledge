# Barry Zhang

## Who

- **In the source:** [[Nate Herk]] names him and [[Mahesh Murag]] as the creators of Agent Skills at Anthropic ([00:24](https://www.youtube.com/watch?v=HIRDzMtuWFk&t=24s)). The captions give "Barry Jien".
- Nate says the pair stopped building a separate agent per job because the underlying agent proved more general-purpose than expected ([00:29](https://www.youtube.com/watch?v=HIRDzMtuWFk&t=29s)).

## In this vault

- [[Nate Herk - Build Skills Instead of Agents]] — referenced; his talk with Murag frames the video.

## Ideas associated with him (as Nate retells them)

- **Model = processor, runtime = operating system, skills = apps** ([00:56](https://www.youtube.com/watch?v=HIRDzMtuWFk&t=56s)). → [[Agent Skills]]
- **Save repeated code in the skill:** Claude kept rewriting a slide-styling script, so it stored one for its future self ([01:46](https://www.youtube.com/watch?v=HIRDzMtuWFk&t=106s)).
- **Skills as a step toward continuous learning.** Nate relays the talk's "guarantee" that whatever Claude writes down, a future Claude can reuse efficiently ([05:28](https://www.youtube.com/watch?v=HIRDzMtuWFk&t=328s)). Agents writing their own skills is only a hope (Beyond the source).
